# Precut downloads

Official Precut installers from T2ETECH.

- [Download from the Store](https://store.t2etech.com/en/products/precut)
- [Latest installer release](https://github.com/Soravit-Ice/Precut-releases/releases/latest)

This repository contains public installer releases. Application features remain subject to the Precut trial or license. Source code is maintained separately.

Each release includes a release-manifest.json and SHA256SUMS. Verify the checksum for the exact filename before installation. Release assets and tags are immutable after publication. Checksums confirm file integrity; OS signing and notarization flags are recorded separately in the manifest.
